
 CyberBrain AI 🛡️

 Segundo cérebro de Inteligência Artificial para Cibersegurança e Pentest Ético

 📌 Sobre o projeto

O CyberBrain AI é um projeto desenvolvido com o Gemini Notebook, com o objetivo de criar um assistente inteligente especializado em Cibersegurança e Pentest Ético.

A ferramenta utiliza fontes técnicas selecionadas para organizar conhecimentos, responder perguntas, explicar vulnerabilidades e auxiliar no aprendizado de segurança da informação.

 🎯 Objetivo

Desenvolver um assistente inteligente especializado em cibersegurança e testes de intrusão, capaz de organizar conhecimentos, explicar vulnerabilidades, apresentar metodologias de Pentest e auxiliar nos estudos com base em fontes técnicas confiáveis.

 📚 Fontes utilizadas

| Fonte | Finalidade |
|---|---|
| NIST SP 800-115 | Metodologia de testes de segurança |
| OWASP WSTG | Testes de segurança em aplicações web |
| MITRE ATT&CK | Táticas e técnicas de adversários |
| Nmap Documentation | Análise e descoberta de redes |
| PortSwigger Academy | Aprendizado e laboratórios práticos |

As fontes foram selecionadas considerando sua credibilidade, relevância técnica e contribuição para o aprendizado.

 🧠 Diretriz da Inteligência Artificial

O CyberBrain AI foi configurado para atuar como professor e assistente técnico em cibersegurança.

Suas principais responsabilidades são:

- Explicar conceitos técnicos.
- Apresentar metodologias de Pentest.
- Identificar e explicar vulnerabilidades.
- Recomendar boas práticas de segurança.
- Utilizar as fontes adicionadas como base para suas respostas.
- Apresentar referências e citações.

 💬 Testes realizados

As seguintes perguntas foram utilizadas para avaliar o funcionamento do notebook:

1. O que é Pentest e quais são suas principais etapas?
2. Qual é a diferença entre vulnerabilidade, ameaça e risco?
3. Como funciona o reconhecimento de uma rede utilizando Nmap?
4. Quais são as principais vulnerabilidades abordadas pelo OWASP Top 10?
5. Como o MITRE ATT&CK organiza as táticas e técnicas utilizadas por adversários?
6. Quais medidas podem proteger dispositivos IoT?
7. Como organizar um plano de estudos de Pentest Ético?

As respostas foram verificadas por meio das citações apresentadas pelo notebook.
